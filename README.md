# Blockchain Course — Artifacts

This repository contains educational materials and practical assignments for the blockchain technology course.

---

## 🧩 Repository Structure

Each folder is a separate course module:

- [module3](./module3) - Practical work on the topic of cryptography. The essence of the work is the application of digital signatures in transactions.
- [module4](./module4) - Practical work on the topic of smart contracts. The essence of the work is to write a React component for interacting with any verified smart contract.
- [module6](./module6) - Practical work on Solidity. The essence of the work is to study Hardhat.
- [module7](./module7) - Practical work on the topic of dApp. The essence of the work is to study the architecture of dApp and write a React component for interacting with a smart contract.

---

## 🏆 Final Project

The final project for this course is the MultisigWallet dApp, a multi-signature wallet based on scaffold-eth-2.

Repository: https://github.com/Masolll/MultisignatureWallet

### 🏗️ Technical Stack
- Solidity
- scaffold-eth-2
- Hardhat
- React
- ethers.js
